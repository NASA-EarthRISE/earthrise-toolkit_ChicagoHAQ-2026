User Guide

The Regional Ozone Precursor Dashboard is a user-friendly tool is designed to allow users to visualize spatiotemporal trends of NO2 pollution across Chicago and its community areas. This manual will guide you through interacting with the different pages and features of this dashboard.

Home (Server Stats) Pollution Map Community Statistics Export Files
Home (Server Stats)

The Regional Ozone Precursor Dashboard homepage consists of general server information, quick actions, introduction to data products, and system status.

Status Cards:

  • The "Data Load Status" stat card tracks the availablity of all three data sources (TEMPO, Open Air Clairty, and Fused) within the server. If this message displays "Complete", all three data products have been properly loaded and sourced within the server. If this message displays "Incomplete", one or more data sources is missing or not found by the server. If this message displays "Failed", no data sources have been found within the server. To remedy data loading issues, refer to the Chicago_HAQ_ReadME file found in the source Github.
  • The "Ground Sensor Network" status card displays a static value of the number of active sensors in the Open Air Chicago network.
  • The "Last Server Update" stat card tracks the last time the server source code was re-run or re-loaded. This card indicates when the last update or change was made to the dashboard UI.

Quick Actions: These buttons link to the main pages of this dashboard.

  • Explore NO2 Pollution: This link will take you to the Daily Pollution Map.
  • Explore Community Statistics: This link will take you to the Community Statistics page.
  • Dashboard User Guide: This link will take you to the User Guide page for a tutorial on how to use this dashboard.
  • Get Data Files: This link will take you to the Export Data Files page.

Data Sources: Clicking "Learn More" under each of the data products links to a description of that data product on the Info page.

System Status: The system status section of the homepage tracks the most recent server updates. These updates may include:

  • Server Start: The last time the server was re-run or re-loaded.
  • Dashboard Reloaded: The last time the dashboard webpage was reloaded.
  • TEMPO Data: The number of available TEMPO data files within the server. If the disclaimer displays "No files loaded", there were no data entries found for TEMPO.
  • Open Air Chicago Data: The number of available Open Air Chicago data files within the server. If the disclaimer displays "No files loaded", there were no data entries found for Open Air Chicago.
  • Fused Data: The number of available Fused data files within the server. If the disclaimer displays "No files loaded", there were no data entries found for the Fused data product.

Pollution Map

The Pollution Map homepage visualizes NO2 for each of the data products: TEMPO satellite measurements, Open Air Chicago ground sensors, and the fused data product. Use the + and - symbols in the top left to zoom in and out of the map. Click the button to reset the zoom to center Chicago.

To start visualizing data, use the left "Parameters" sidebar to choose an Observation Window, Data Product, and Spatial Scale and see the corresponding data appear on the map to the right.

1. Choose Hourly, Daily, or Monthly as your Observation Window and then select a date or date range.

  1. Hourly: Select one date to see how NO2 changes on an hourly basis during that day. Keep in mind the general date and time ranges that are available for each product:
    • TEMPO: September 4, 2025 — June 1, 2026 (Daylight Hours)
    • Open Air Chicago: September 1, 2025 — June 1, 2026 (All 24 Hours)
    • Fused Dataset: September 4, 2025 — June 1, 2026 (Daylight Hours)
  2. Daily: Select a date range to see how NO2 changes on a daily basis during that time range. Keep in mind the general date ranges that are available for each product:
    • TEMPO: September 4, 2025 — June 1, 2026
    • Open Air Chicago: September 1, 2025 — June 1, 2026
    • Fused Dataset: September 4, 2025 — June 1, 2026
  3. Monthly: Select a month range to see how NO2 changes on a monthly basis during that time range. Keep in mind the general date ranges that are available for each product:
    • TEMPO: September 2025 — May 2026
    • Open Air Chicago: September 2025 — May 2026
    • Fused Dataset: September 2025 — May 2026
2. After choosing a valid Observation Window and Date Selection, choose the Data Product you want to visualize: TEMPO, Open Air Chicago, or Fused (TEMPO + Open Air Chicago).

3. Select the Spatial Scale you want to visualize the data on. TEMPO and the Fused data are available on an Individual Grid Cell (pixel) level and aggregated to Chicago's Community Areas. Open Air Chicago is available on an Individual Sensor level and aggregated to Chicago's Community Areas.

4. Click the "Load" button in the navy date selection box to load your data on the map. Click "Play" on the bottom of the map to see how NO2 changes over time. Hover over or click on any individual sensor, pixel, or community area to see a pop-up with the location, time, and NO2 value. You may need to pause the playback to read the pop-ups.


Data not displaying? Some data products are missing dates and pixels, which is normal and often a symptom of the data cleaning process. If a date has no data available for the selected data product, a warning symbol will pop up on the map to let you know that there is no data available for that specific date. If you are trying to visualize TEMPO or Fused data on the Hourly Map, use the time slider at the bottom of the map to change the Hour to daylight hours (typically 6am to 6pm in spring and fall, and 7am to 5pm in winter) to make sure that the missing data is not due to the time you are looking at.

Community Statistics

This page visualizes NO2 statistics on a community level for each of the data products: TEMPO satellite measurements, Open Air Chicago ground sensors, and the fused data product.

1. Select a community area from the dropdown on the left side of the page.

  1. If you do not know the community area a specific address is in, click on the blue “Get Help” button below the map. This will take you to an external site created by the City of Chicago. Once you are on this site, click the search magnifying glass in the top left corner to search up an address and get the name of the community area the address is in.

2. After you have selected a community, graphs will populate on the right side of the page visualizing different statistics. By default, the selected statistics percentile is the Ground Sensors (Open Air Chicago) for that community. Select the “TEMPO” or the “Fused”radio buttons to see data visualizations for a different data product.

3. If you would like to save a PDF of the community statistics page, click on the “Save as PDF” button in the top right corner of the page just below the navigation bar.

Export Files

This page allows you to export the data files used in the dashboard.

1. Under the Export Data Files left sidebar, first choose a Data Source, depending on whether you want to download TEMPO, Open Air Chicago, or Fused data.

2. Choose the spatiotemporal scale you want to download data for:

  • Hourly: Hourly concentrations of NO2
  • Daily Community Average: Average daily NO2 concentrations aggregated to Chicago's communities
  • Daily Averages: Average daily NO2 concentrations for each pixel (TEMPO and Fused data) or by sensor (Open Air Chicago)
  • Monthly Community Average: Average monthly NO2 concentrations aggregated to Chicago's communities
  • Monthly Average: Average monthly NO2 concentrations for each pixel (TEMPO and Fused data) or by sensor (Open Air Chicago)

3. (Optional): Choose a date filter to filter the files to a certain month.

4. Choose the export format. Most files in their original format will export as a .geojson or .json if "Original" is selected as the export format. If you want to export all selected files as a .csv, click the “CSV” button for the export format.

5. On the right side of the page, you can click the “Select All” checkbox to select all data files for download or instead choose individual file names to download.

6. Click the "Download Selected” button in the left sidebar to download selected files. If all files have been downloaded successfully, there will be a confirmation under this button.

7. If there is trouble viewing newly added data files as a downloadable option, click the "Refresh List" to keep the list the file list up to date.
